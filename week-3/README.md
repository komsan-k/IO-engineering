# Week 3 Overview: Connectivity & Messaging Protocols

Week 3 introduces **wireless connectivity and IoT communication protocols** for connecting embedded devices to networks, cloud services, and mobile applications. Students develop practical skills in **Wi-Fi, HTTP, MQTT, BLE, and low-power communication**.

## Learning Flow

**Wi-Fi & HTTP → MQTT → BLE → Low-Power & LPWAN**

## Weekly Topics

| Slot | Topic | Key Skills |
|------|-------|------------|
| **9** | Wi-Fi Networking & HTTP | Wi-Fi connection, NTP, REST APIs, HTTP GET/POST |
| **10** | MQTT Telemetry | Publish/subscribe, brokers, QoS, JSON sensor data |
| **11** | Bluetooth Low Energy | BLE, GAP, GATT, sensor services, notifications |
| **12** | Low-Power & LPWAN | Sleep modes, deep sleep, wake-up mechanisms, LPWAN |

## Learning Outcomes

By the end of Week 3, students should be able to:

- Connect embedded devices to Wi-Fi networks and web services.
- Exchange IoT data using HTTP and REST APIs.
- Implement MQTT-based sensor telemetry and remote control.
- Develop BLE services for wireless sensor communication.
- Apply low-power techniques for energy-efficient IoT devices.
- Understand the role of LPWAN in long-range, low-power IoT systems.
