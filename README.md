# 📘 Module : Inteligent Object Engineering 977-331
## Part-2: Embedded & Connected Systems + FPGA (HLS) Course Plan

## 🗂 Course Overview

This 4-week intensive course covers:

* Embedded Systems fundamentals
* Connected Systems (IoT communication)
* ML-based integration
* FPGA acceleration using High-Level Synthesis (HLS)

Each week consists of **4 time slots**, each **3 hours**.

---

## 🗓️ Week 1: Embedded Systems Fundamentals

### 🔹 Slot 1: Embedded Systems – Architecture

* MCU vs MPU
* Input/Output systems
* System architecture mapping

### 🔹 Slot 2: Embedded Systems – Programming

* Embedded Software
* Interupttion techniques
* Toolchains (Arduino, ESP-IDF, micorPython)


### 🔹 Slot 3: Embedded Systems – HW Interfaces

* GPIO, ADC, PWM
* UART, I2C, SPI
* Sensor interfacing

### 🔹 Slot 4: Embedded Systems – Real-Time OS

* RTOS concepts
* Task scheduling
* FreeRTOS basics

---

## 🌐 Week 2: Connected Systems (Communication Layer)

### 🔹 Slot 1: Connected Systems – Technology

* IoT architecture
* Cloud communication 

### 🔹 Slot 2: Connected Systems – HTTP

* REST API
* Client-server model

### 🔹 Slot 3: Connected Systems – WiFi

* TCP/IP basics
* ESP32 WiFi integration

### 🔹 Slot 4: Connected Systems – Bluetooth

* BLE fundamentals
* Device communication

---

## 🔗 Week 3: Advanced Connectivity & Integration

### 🔹 Slot 1: Device-to-Device (ESP-NOW) 

* D2D communication basics
* Non-IP communication introduction

### 🔹 Slot 2: Mesh Network (ESP-Mesh)

* WiFI Mesh architecture
* Multi-Hop Network

### 🔹 Slot 3: WiFi–Bluetooth Cooperation 

* Hybrid communication models
* System design

### 🔹 Slot 4: ANN for Connected WiFi

* ANN Structure
* RSSI Signal Classifier

---

## ⚡ Week 4: FPGA & High-Level Synthesis (HLS)

### 🔹 Slot 1: FPGA – HLS 1

* FPGA fundamentals
* HLS workflow (C → HDL)

### 🔹 Slot 2: FPGA – HLS 2

* Loop optimization
* Pipelining

### 🔹 Slot 3: FPGA – HLS 3

* Latency & throughput optimization
* Resource utilization

### 🔹 Slot 4: FPGA – HLS 4

* Case study: AI / DSP accelerator
