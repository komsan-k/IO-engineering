# Week 2 Overview: Real-Time Operating Systems (RTOS)

Week 2 introduces **real-time operating system concepts** for developing concurrent and multitasking embedded applications. Students learn how FreeRTOS manages **tasks, scheduling, shared resources, inter-task communication, software timers, and memory** through practical laboratory exercises.

## Learning Flow

**Tasks & Scheduling → Synchronization → Queues → Timers & Memory Management**

## Weekly Topics

| Slot | Topic | Key Skills |
|------|-------|------------|
| **5** | Concurrency & Multitasking | FreeRTOS tasks, priorities, scheduling, preemption |
| **6** | Semaphores & Mutexes | Race conditions, critical sections, synchronization |
| **7** | Inter-Task Communication | Queues, producer-consumer model, thread-safe data exchange |
| **8** | Timers & Memory Management | Software timers, heap monitoring, dynamic/static allocation |

## Learning Outcomes

By the end of Week 2, students should be able to:

- Create and manage multiple FreeRTOS tasks.
- Apply task priorities and understand preemptive scheduling.
- Protect shared resources using semaphores and mutexes.
- Exchange data safely between tasks using queues.
- Implement periodic operations using software timers.
- Monitor and manage memory usage in RTOS-based embedded systems.
