# Week 4 Overview: Edge AI & Embedded Security

Week 4 introduces **intelligent and secure embedded systems**, focusing on deploying machine-learning models directly on microcontrollers and protecting embedded devices. Students develop practical skills in **TinyML, model optimization, edge inference, cryptography, secure boot, and secure firmware updates**.

## Learning Flow

**Data Collection → Model Optimization & TinyML → Edge Inference → Embedded Security**

## Weekly Topics

| Slot | Topic | Key Skills |
|------|-------|------------|
| **13** | Data Collection for Machine Learning | TinyML, IMU data collection, feature extraction, dataset preparation |
| **14** | Model Quantization & Deployment | INT8 quantization, pruning, TensorFlow Lite for Microcontrollers |
| **15** | Edge Inference & Actuation | Real-time inference, classification, latency, memory management, local control |
| **16** | Embedded Cryptography & Secure Boot | AES-256, SHA-256, secure boot, Root of Trust, secure OTA |

## Learning Outcomes

By the end of Week 4, students should be able to:

- Collect and prepare sensor datasets for embedded machine learning.
- Optimize ML models using quantization and pruning.
- Deploy TinyML models on microcontrollers.
- Perform real-time edge inference and local actuation.
- Apply basic cryptographic techniques to embedded systems.
- Understand secure boot, Root of Trust, and secure OTA firmware updates.
